# 🧵 В гостях у Мастерицы (Handmade-галерея Татьяны)

Уютный сайт-витрина для демонстрации изделий ручной работы: вышивки крестиком и бисером, ажурных салфеток крючком и вязаных носочков.

---

## 🌟 Основные возможности

- **Дизайн в тёплых кремовых тонах**: подчёркивает теплоту и уют изделий ручной работы.
- **Поддержка тем оформления**: переключение между тёмной и светлой темами (`🌙` / `☀️`).
- **Двуязычность (RU / DE)**: мгновенный перевод интерфейса без перезагрузки страницы.
- **Интерактивная галерея**:
  - Карточки с кнопками разворачивания/сворачивания подробного описания (`▾` / `▴`).
  - Полноэкранный просмотр фотографий по клику.
  - Автоматическое скрытие отсутствующих изображений (без некрасивых заглушек).
- **Прямая форма связи**: отправка сообщений мастеру через протокол `mailto:` на почту `tanchebur@gmail.com`.
- **Подвал сайта**:
  - Ссылка на `Impressum` (правовая информация).
  - Локальный счётчик просмотров на `localStorage`.
